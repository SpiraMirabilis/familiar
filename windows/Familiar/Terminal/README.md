The terminal LLM agents (`/agent`) run in, in a WebView2 in the side dock: `terminal.html` on
[xterm.js](https://github.com/xtermjs/xterm.js) (MIT, the xterm.js authors).

- `xterm.js` and `xterm.css`: `@xterm/xterm` 6.0.0, from its npm package (`lib/`, `css/`).
- `addon-fit.js`: `@xterm/addon-fit` 0.11.0, from its npm package (`lib/`).

To update, replace them with the same files from newer packages.
